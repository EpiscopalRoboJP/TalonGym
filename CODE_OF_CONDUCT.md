# Code of conduct

TalonGym is built for FTC students, mentors, and volunteers. We expect everyone in issues, PRs, and discussions to:

- Be respectful and assume good intent
- Stay on the supported use: train offline, export a trajectory, paste into an AUTO OpMode
- Not request or share ways to cheat a MATCH or bypass FIRST rules
- Not post secrets, personal data, or unofficial copies of FIRST CAD/manuals that you are not allowed to redistribute

Unacceptable behavior includes harassment, personal attacks, and publishing others' private information.

Report conduct problems the same way as a security issue: privately to the maintainers ([TalonStrikeJP](https://github.com/TalonStrikeJP)), not in a public issue if it involves a person.

Maintainers may edit or close comments, refuse PRs, or block accounts that break this.
